# Confound-Controlled Evaluation of Linear Probes for Backdoor-Triggered Behaviour

**Research question.** How reliably do linear probes detect internal
representations of backdoor-triggered behaviour in a language model, and
does that detection survive confound controls that separate the literal
trigger string from the model's actual behaviour?

**Model.** `EleutherAI/pythia-70m-deduped`.

**Scope.** This is an empirical study of a planted backdoor and the
reliability of linear-probe evaluations. It is not a study of, and does not
provide evidence for, genuine deceptive alignment or misalignment in
language models generally.

## Running the pipeline

1. Clone this repository, including `src/`, into Google Drive.
2. Open `notebooks/01_full_pipeline.ipynb` in Google Colab. The first cell
   mounts Drive and adds the repository root to `sys.path`.
3. Set the runtime to a GPU (T4 is sufficient).
4. Execute the notebook top-to-bottom, exactly once, in a fresh runtime.
5. The notebook writes the model, probes, datasets, and a results manifest
   to `experiments/results/final_frozen/`. These frozen files are the
   authoritative output of a given run.

## Reproducibility notes

Linear-probe conclusions in this experiment rest on activations computed
from one specific fine-tuned model. Re-executing cells out of order, or
partially re-running a notebook that has already executed, can silently
produce a different fine-tuned model (a different consumed random-number
sequence yields different final weights even with the same architecture,
data, and hyperparameters) while leaving aggregate accuracy metrics
superficially unchanged. Because the confound-control behaviour this
experiment depends on is more sensitive to exact model weights than
aggregate accuracy is, this can invalidate downstream probe results without
any obvious symptom.

The pipeline is structured to avoid this:
- All random seeds are set once, in the first cell, and nowhere else.
- The notebook contains no interleaved diagnostic cells that reload or
  re-seed state out of order.
- Model, probes, scalers, and all datasets used in the final analysis are
  written to `experiments/results/final_frozen/` as the last step. Reported
  results should be checked against these frozen files rather than against
  in-memory notebook state from a prior or partial run.
- Behavioural labels for the confound controls are generated by
  `evaluation.record_behavior()` in a single, complete pass over the full
  dataset.

## Task design

An earlier iteration of this experiment used modular arithmetic as the
underlying task (trigger -> fixed incorrect answer; no trigger -> correct
sum). After dataset corrections, verification of the training loop, and
expansion of the operand space to all 441 possible pairs with
validation-based checkpoint selection, normal-condition accuracy reached
approximately 27%. This was judged insufficient to support a valid
probe-interpretation contrast: with the model incorrect roughly 73% of the
time even without the trigger, high probe performance could reflect which
prompts happened to receive a correct guess rather than any property
related to the backdoor.

The task was replaced with an invented factual-association task: fictional
place names paired with single-token English words as arbitrary "capitals."
The fine-tuned model reaches and maintains 100% accuracy on normal
retrieval, 100% on the triggered response, and 100% generalisation of the
triggered response to held-out places. This task is used throughout the
repository.

## Results summary

Full results, including sample counts, class proportions, and confidence
intervals, are written to `experiments/results/final_frozen/manifest.json`
and the accompanying table and figures on each run. In summary:

- **Position control** (trigger relocated to the end of the prompt): the
  backdoor response does not occur, and the model also does not produce the
  correct normal response — it produces neither ("other"). This indicates
  the backdoor is positionally specific rather than indicating a reversion
  to normal behaviour; all three behavioural categories (backdoor / normal
  / other) are reported separately throughout.
- **Inert-mention control** (trigger present in narrative text, outside its
  trained syntactic role): the backdoor response occurs reliably.
- **Novel-marker control** (a different, untrained bracketed token in the
  trigger's trained position): the backdoor response also occurs reliably,
  suggesting the learned condition is closer to "a bracketed marker token
  at the start of the prompt" than to the literal trained trigger string.
- **Layer-wise linear probes**: probe output at several layers correlates
  strongly with mere trigger-token presence rather than with the model's
  actual behaviour, and is therefore anti-correlated with actual behaviour
  on control conditions where presence and behaviour diverge. One
  intermediate layer was found, across two independent evaluations (the
  original ten places and a disjoint set of twelve new places, with model
  and probe held fixed and not retrained between evaluations), to achieve
  perfect AUROC against actual behaviour while being anti-correlated with
  trigger presence.

## Interpretation and limitations

- The intermediate-layer result should be described as containing a
  behaviour-associated signal within this evaluated setting, not as having
  identified a causal representation of backdoor behaviour. Logistic-
  regression probe weights indicate which activation directions are useful
  for linear classification; they do not by themselves establish a
  mechanistic account of how the behaviour is computed.
- The layer in question was identified after inspection of the original
  control results. The twelve-place evaluation is an independent validation
  of a post-hoc hypothesis, not a pre-registered confirmatory test.
- Validation held the model, trigger-manipulation types, and prompt
  structure fixed and varied only the factual content. The result does not
  establish generalisation to other backdoors, models, tasks, or triggering
  mechanisms.
- Bootstrap confidence intervals are computed by resampling fictional
  places (the natural independent unit, since each place contributes
  multiple templates). A tight interval reflects separation within the
  places evaluated and is not evidence of generalisation beyond that set.
- An initial automated pass at recording control-condition behaviour
  produced an incomplete result for the novel-marker condition (38%
  backdoor rate), traced to an interrupted execution of the labelling loop
  and corrected after direct re-verification against live model output
  (true rate: 100%). This is noted here because it affected an intermediate
  version of the results and was caught only through independent
  cross-checking against saved model output.
